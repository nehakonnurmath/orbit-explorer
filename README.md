# Orbit Explorer

Problem Description: Develop an interactive 3D space exploration platform that simulates planetary motion and enables users to explore, analyse, and compare celestial bodies through a synchronized visualization and data interface. Requirements: 1. Create a 3D solar system containing at least 5 celestial bodies, including the Sun. 2. Implement animated orbital movement with controls to pause, resume, and adjust animation speed. 3. Allow users to select, rotate, and zoom into celestial bodies, with a reset-view option. 4. Display dynamic planetary information, including diameter, distance from the Sun, and orbital period. 5. Implement a comparison feature for two selected planets, with at least 3 parameters and a visual comparison chart. 6. Provide search or filtering functionality; selecting a search result must focus the corresponding celestial body. 7. Ensure the visualization and information panels remain synchronized when users switch between planets
